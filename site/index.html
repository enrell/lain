[ core ]

Everything beyond the core
is a plugin.

Bound to capability names, health-checked, swappable at runtime with generation fencing. The server stays useful even with pieces missing.

registry

One invoke surface, many providers

Capabilities resolve through a composition: exactly-one, ordered-many, first-accepted, merge-many. Swaps are fenced by generation so a stale writer can never overwrite newer state.

source identify catalog userstate playback search metadata thumbnail
generation 1 · stale writers fenced
stream

Direct play, Range by Range

Media bytes never cross a plugin call. The gateway authorizes, resolves identity and serves the file with HTTP Range.

206 Partial Contentmatroska · hevc
thumbnails

Stills on demand

ffmpeg extracts one frame, the provider caches it on disk, the gateway streams it. No ffmpeg? Only this capability degrades.

t=08s
GET /api/items/<id>/thumbnail?t=8&w=480
metadata

Merged, scored, cached

Local NFO plus remote providers merge by title match and precedence; overlays decorate the catalog without touching identity or progress.

NFO Kitsu AniList Jikan merge-many → best pick
progress

Resume that survives reindexing

User state lives outside the catalog. Bounded writes, per user, never on every video event.

S02E04resume 18:32
surfaces

One origin, three clients

The Svelte 5 SPA is compiled into the Go binary — same process, same origin, no Node at runtime. The CLI drives mpv; the desktop client is Qt 6 + libmpv.

[ pipeline ]

Enumerate. Identify.
Catalog. Plan. Stream.

A policy-free ingest pipeline wired from plugins you can replace one by one. Unidentified files count, they never abort a scan.
