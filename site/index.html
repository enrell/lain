VI Terminal

The same binary is the client.

Search, play in mpv, keep offline copies, back up. No browser needed.

$ lain watch frieren  # search, pick, play in mpv
$ lain watch --next  # resume the first unfinished
$ lain download add frieren --rest  # offline copies from here on
$ lain doctor  # what this machine can do
$ lain backup --out backups  # online, consistent

VIII Install

Running in a minute.

Open http://localhost:9360, create the first account, point lain at a folder.

The image runs on amd64 and arm64 and brings ffmpeg with it.

docker run -d --name lain \
  -p 9360:9360 \
  -v lain-data:/data \
  -v ~/Videos:/media/videos \
  ghcr.io/enrell/lain:latest

The same container as a compose file. Add a volume per media folder.

services:
  lain:
    image: ghcr.io/enrell/lain:latest
    ports: ["9360:9360"]
    volumes:
      - lain-data:/data
      - ~/Videos:/media/videos
    restart: unless-stopped
volumes:
  lain-data:

An interactive script: Docker, a static binary or a user service, your media folders, the port. It prints what it will do before doing it, and the same script uninstalls.

curl -fsSL https://raw.githubusercontent.com/enrell/lain/main/scripts/install.sh | bash

Read the script first

One static file for Linux, macOS and Windows, with the web client inside. Each archive ships with its SHA-256. Put it on your path and run it.

lain serve                 # http://localhost:9360
lain service install       # or keep it running as a user service
